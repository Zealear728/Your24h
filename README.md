# Your 24h · 你的24小时

一个独立的个人日程 Web App。用鼠标在一天的时间轴上画出安排；没有账户、后端或外部日历集成。

技术：Vue 3、TypeScript、Vite、普通 CSS。运行时只有 Vue 一个直接依赖，拖动由原生 Pointer Events 实现。

## 安装与启动

先安装 Node.js（建议 Node 24.15 或更新的兼容版本）。在本项目文件夹打开终端，运行：

```sh
npm ci
npm run dev
```

然后在浏览器中打开终端显示的本地地址，通常是 `http://127.0.0.1:5173/Your24h/`。关闭终端或按 `Ctrl+C` 可停止服务。现在配置了 GitHub Pages 的项目路径 `/Your24h/`；只改变同一来源下的路径不会清空原来根路径的 localStorage。

如果已经安装依赖，只需 `npm run dev`。

生成正式版本并本地预览：

```sh
npm run build
npm run preview
```

预览地址通常为 `http://127.0.0.1:4173/Your24h/`。正式文件在 `dist/`，可以托管到静态网站服务。不要直接双击 `dist/index.html`。

**重要：**安排保存在当前浏览器、当前网站来源对应的 localStorage 中。开发地址与预览地址的端口不同，数据各自独立；`localhost` 和 `127.0.0.1` 也不同。日常使用请固定同一地址、端口和浏览器。清除网站数据或结束隐私浏览可能清空安排。应用提供手动 JSON 备份，不跨设备自动同步。

## Release 01：备份与 GitHub Pages 发布

本轮只完成代码和部署准备，**尚未执行提交、推送或线上发布，也未确认线上地址可用**。开始时已确认在 `main`、工作区干净，远程仓库为 `Zealear728/Your24h`，保留了全日概览和极夜星图。

### 先备份原来的日程

1. 在项目文件夹运行 `npm run dev`，用你原来保存日程的浏览器、主机名和端口打开应用。例如，之前使用 `http://localhost:5173`，现在打开 `http://localhost:5173/Your24h/`；如果原来使用 `127.0.0.1`，请继续用它。
2. 先 Enter 保存需要保留的标题；未提交输入不包含在备份中。
3. 顶部工具栏点「数据备份」→「导出备份」。浏览器会下载 `your24h-backup-YYYY-MM-DD.json`，包含所有日期的已保存时间块，不仅是当天。
4. 在浏览器下载列表确认文件存在，妥善放在项目文件夹之外。不要把个人备份放进 `public/`、`dist/` 或 Git 仓库。

备份含 `format: "your24h-backup"`、`version: 1`、UTC 导出时间和 `blocks`。文件名使用当地日期；时间块日期仍为当地 `YYYY-MM-DD`。不包含账户、主题偏好或未保存草稿，不会发送给服务器。

### 导入备份

点「数据备份」→「导入备份」，选择本地 JSON。应用会先完整检查格式、版本、ID 唯一性、日期、30 分钟网格、00:00–24:00 范围、非空标题、有效颜色和同日重叠。

校验成功后显示日期数和时间块数，并明确提示整份替换。可以先点击「先导出当前已保存数据」，然后主动勾选替换确认，点「确认替换并恢复」。空备份会额外提示将清空日程。未提交标题在真正确认替换后会取消；需要保留时先取消导入、保存标题，再操作。

确认前不写入数据；任一记录非法会拒绝整份备份。恢复先完成一次 localStorage 写入，再更新画布；写入失败保留原有日程与草稿。取消导入、关闭菜单不覆盖数据。成功后普通模式和全日概览立即更新，当前日期与 Light / Dark 偏好保持不变。

旧版合法的原始 TimeBlock 数组也可严格校验后恢复；缺省颜色按原规则显示为 Sage，旧燕麦 `neutral` 继续有效。不提供数据合并或自动冲突处理。

### 确认部署并恢复日程

1. 打开仓库的 [Actions](https://github.com/Zealear728/Your24h/actions)，找到 **Deploy Your 24h to GitHub Pages**。
2. 等待 `build` 和 `deploy` 两个任务都变绿；若失败，打开失败步骤查看原因。未在推送时触发，可在工作流页面使用 **Run workflow**，选择 `main`。
3. 点击成功部署记录中的页面链接，或在 Settings → Pages 查看发布地址。预期地址为 [Your 24h 正式站点](https://zealear728.github.io/Your24h/)，**以实际部署成功后的结果为准**。
4. 在正式网站点「数据备份」→「导入备份」，选择之前从原 localhost 页面导出的文件，核对日期数和时间块数，再主动确认恢复。
5. 检查今天、其他日期、颜色、全日概览，刷新页面后再确认数据仍在。

localhost 与 `https://zealear728.github.io` 是不同来源，localStorage **不会自动共享**。部署代码不会携带你的本地日程；正式站点的数据仍只存在该浏览器中。不同设备、不同浏览器之间要手动导出 / 导入，本轮没有云同步。

以后每次把新代码正常推送到 `main`，同一工作流会自动重新测试、构建并更新固定网址；不需要每天运行开发服务。网站更新不会主动清空日程，但清理网站数据、换浏览器或改域名不会自动迁移数据，请定期导出备份。

## 怎么使用

- **单击空白**：按所在半小时格新建 30 分钟安排。
- **按住空白拖动**：上下两个方向均可创建；松手后直接输入名称。
- **标题输入**：Enter 保存，Esc 取消；失焦时保存非空标题。新块无标题会取消；已有块提交空标题会保留旧标题。中文输入法选词时的 Enter 不会提前保存。
- **改名**：点击时间块标题。
- **移动**：抓住时间块空白部分或右侧六点手柄上下拖动，时长保持不变。
- **调整大小**：拖动顶部或底部约 9px 的操作区，至少保留 30 分钟。
- **删除、颜色**：悬停时间块，使用右侧垃圾桶或调色板按钮；键盘聚焦后也会显示这些按钮。新建块默认在绿、紫、蓝、橘、粉五色中依次轮换，可以随时手动改色。
- **切换日期**：前后箭头，或日期旁的原生日期选择器；「今天」回到今天。
- **跳到现在**：只在今天可用。当前时间线每 15 秒更新一次。
- **全日概览**：工具栏一键查看完整 00:00–24:00，概览只读。点击块或空白返回对应时间附近；直接用「返回编辑」退出会恢复之前的滚动位置。

所有时间以 30 分钟吸附。单击取所在时间格；拖动起止点取最近的半小时刻度。超过约 6px 才按拖动处理。从 14:00 刻度拖到 16:00 刻度会得到恰好 2 小时。拖到滚动区上下边缘会自动滚动画布。

一天范围是 00:00–24:00。创建和调整大小会停在相邻块边缘；移动到重叠处会显示红色条纹和文字，松手回到原位置。相邻块可以首尾相接。拖动时按 Esc、收到 pointercancel、丢失指针捕获、窗口失焦或切换日期都会取消预览；中途预览不写入存储。

键盘辅助操作：Tab 聚焦画布，上下键选择时间，Enter 新建。Tab 聚焦块的六点移动按钮，上下键移动，Shift + 上下键调整结束，Alt + Shift + 上下键调整开始，Delete / Backspace 删除。

以桌面鼠标操作为主要验收目标。窄屏提供响应式排版；触屏滚动画布优先，手机手势需另行人工验证。

## Visual Polish 01

- 品牌区与画布统一居中，桌面宽度约为窗口的 90%，最大 1760px；小窗口逐级缩小外边距。
- 页面以窗口高度组织，时间轴填满标题和工具栏以外的剩余高度，保留每小时 80px 和完整 24 小时内容。正常桌面窗口主要滚动时间轴，不通过隐藏页面溢出来裁切内容。窗口高度低于 480px 时允许页面滚动，保证控件仍可访问。
- 标题区和工具栏减少纵向留白；窄窗口工具栏可以换行，低高度窗口进一步收紧间距。
- 30 分钟块维持原有 37px 可见高度（40px 时间跨度减去 3px 块间间隔），采用单行紧凑布局；窄窗口隐藏次要时间信息，完整时间可通过标题悬停提示或无障碍名称读取。输入标题时优先给输入框空间；短块的边缘热区避开右侧操作按钮。

当前五色配置集中在 `src/domain/palette.ts`：

| 颜色 | 背景 | 左侧点缀 |
| --- | --- | --- |
| Sage 绿 | `#D7E6C4` | `#91AD70` |
| Lavender 紫 | `#DFD0F4` | `#A68ACB` |
| Sky 蓝 | `#BFDFF0` | `#77B2D4` |
| Peach 橘 | `#F5D3BB` | `#D69C73` |
| Rose 粉 | `#F1CFD8` | `#CC94A8` |

默认颜色取最后一个仍保留的已创建块的当前颜色，按“绿 → 紫 → 蓝 → 橘 → 粉 → 绿”选下一种；没有块或最后一块为旧燕麦色时，从绿开始。轮换依据保存数组的创建顺序，和时间轴排序、日期无关。草稿取消或空标题不消耗颜色；手动改最后一个块的颜色后，下一块从其后接续。删除最后一个块后，从剩余最后一个块接续。颜色随有效标题保存，不新增存储键或业务字段。

旧 `neutral`（燕麦）颜色值与外观继续兼容保留，不出现在新的五色选择器中；已有块不会自动改色。读取或切换日期不触发存储重写，存储键仍为 `day-canvas.blocks.v1`。

本轮自动检查包含新色文字对比度、颜色轮换与取消、手动改色和旧记录保留，以及不同画布宽度、位置下的创建、移动、resize。坐标测试使用模拟 DOM 矩形，**不代表真实浏览器窗口验证**。本轮未启动真实浏览器、Tauri 或 Windows UI 自动化。

## Dark Mode 01

日期工具栏的太阳 / 月亮按钮显示当前 `Light` 或 `Dark` 模式，点击即可手动切换，不按一天中的时间自动切换。

- 第一次访问、没有有效保存偏好时跟随操作系统；在用户手动选择以前，也响应系统的浅色 / 深色设置变化。
- 手动选择使用独立的 `your-24h.theme.v1` 存储键保存，之后优先于系统设置。刷新、重新打开相同地址仍会恢复选择。
- 主题切换只更新界面颜色，不修改日程或颜色 ID。旧燕麦色也有对应的夜间外观，切回浅色恢复原来的显示。
- 鼠标按下主题按钮不会抢走标题输入焦点；未保存文本、光标选区、日期与滚动位置会保留。输入框原有的 Enter / Esc / 失焦规则继续生效。
- 本地存储受限时仍可切换主题，但会提示无法记住偏好。日程保存与主题保存互相独立。

`src/themes.css` 集中定义两套界面变量；`src/domain/palette.ts` 为原有五种颜色及旧燕麦色提供浅色、深色表面。Dark Mode 01 的暖咖啡视觉已由下方 Dark Mode 02 的极夜星图配色替换，仍然只有 Light / Dark 两种模式。工具栏、原生日期选择器、滚动条、当前时间线、拖动选区、冲突、输入、hover / focus 和 resize 状态均有夜间配色。

`public/theme-init.js` 在页面头部同步读取主题偏好，配合 HTML 中的首帧背景和 `color-scheme`，在 Vue 启动前应用主题，以减少深色刷新时的浅色闪烁。不添加整页主题动画；已有细微反馈仍遵守 `prefers-reduced-motion`。

新增测试包括首帧脚本与 Vue 的默认模式一致、手动覆盖系统、刷新恢复、读写受限、监听清理、深色文字与边缘对比度，以及切换时保留输入节点、焦点、选区、草稿和拖动状态。DOM 模拟不能证明浏览器实际绘制、原生控件和首帧没有闪烁；仍未启动真实浏览器或进行 Windows UI 自动化。

## Full Day Overview 01

普通编辑模式仍为每小时 80px、30 分钟吸附，保持原有创建、移动、resize、颜色轮换及保存规则。工具栏「全日概览」切换到独立的只读组件，复用当前日期的已保存时间块。

- 概览几何位置为 `开始分钟 / 1440`，高度为 `持续分钟 / 1440`，通过百分比适应容器高度，不使用整体 `transform: scale()`，不为了文字增加块高。
- 可用高度充足时显示每小时标签；空间较小时减少标签。块高至少 22px 才显示标题，至少 42px 才增加时间；更短的块只显示色块，可悬停查看完整标题和时间。
- 正常桌面窗口完整呈现一天；概览内部最小画布为 240px，极矮窗口允许内部滚动，避免刻度挤压。Light / Dark 及极夜星图颜色均沿用现有变量和颜色 ID。
- 点击块：退出概览并定位到块的开始附近；点击空白：按点击的相对高度定位，不创建时间块。回到普通模式后，下一次正常单击或拖动才会创建。
- 用工具栏或 Esc 直接返回：恢复当前日期上次进入概览前的滚动位置。概览中切日期保持概览；若该日期没有之前的滚动快照，退出时默认到今天的当前时间或其他日期的早上 8 点附近。
- 概览里的「跳到现在」返回普通模式并定位当前时间。键盘可 Tab 聚焦概览时间块后 Enter 定位；聚焦概览空白时，上下键按小时选位置、Enter 定位。
- 切换视图会取消未完成的拖动预览，旧的 pointerup 不能提交。标题输入暂时挂起；鼠标点击视图按钮不会触发失焦保存，返回同一天可继续输入、保存或取消。概览浏览其他日期不会提交草稿；返回原日期仍可继续。
- 概览只展示已保存块，不展示未提交的新建草稿。视图和滚动快照只保存在本次页面内存，刷新默认回普通模式；没有新增日程字段或 localStorage 键。
