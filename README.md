# 每天 · 时间画布

一个独立的个人日程 Web App。用鼠标在一天的时间轴上画出安排；没有账户、后端或外部日历集成。

技术：Vue 3、TypeScript、Vite、普通 CSS。运行时只有 Vue 一个直接依赖，拖动由原生 Pointer Events 实现。

## 安装与启动

先安装 Node.js（建议 Node 24.15 或更新的兼容版本）。在本项目文件夹打开终端，运行：

```sh
npm ci
npm run dev
```

然后在浏览器中打开终端显示的本地地址，通常是 `http://127.0.0.1:5173`。关闭终端或按 `Ctrl+C` 可停止服务。

如果已经安装依赖，只需 `npm run dev`。

生成正式版本并本地预览：

```sh
npm run build
npm run preview
```

预览地址通常为 `http://127.0.0.1:4173`。正式文件在 `dist/`，可以托管到静态网站服务。不要直接双击 `dist/index.html`。

**重要：**安排保存在当前浏览器、当前网站地址对应的 localStorage 中。开发地址与预览地址的端口不同，数据各自独立；`localhost` 和 `127.0.0.1` 也不同。日常使用请固定同一地址、端口和浏览器。清除网站数据或结束隐私浏览可能清空安排。该 MVP 不跨设备同步，也不提供备份功能。

## 怎么使用

- **单击空白**：按所在半小时格新建 30 分钟安排。
- **按住空白拖动**：上下两个方向均可创建；松手后直接输入名称。
- **标题输入**：Enter 保存，Esc 取消；失焦时保存非空标题。新块无标题会取消；已有块提交空标题会保留旧标题。中文输入法选词时的 Enter 不会提前保存。
- **改名**：点击时间块标题。
- **移动**：抓住时间块空白部分或右侧六点手柄上下拖动，时长保持不变。
- **调整大小**：拖动顶部或底部约 9px 的操作区，至少保留 30 分钟。
- **删除、颜色**：悬停时间块，使用右侧垃圾桶或调色板按钮；键盘聚焦后也会显示这些按钮。新建块默认在绿、紫、蓝、橘、粉五色中依次轮换，可以随时手动改色。
- **切换日期**：前后箭头，或日期旁的原生日期选择器；「今天」回到今天。
- **跳到现在**：只在今天可用。当前时间线每 15 秒更新一次。

所有时间以 30 分钟吸附。单击取所在时间格；拖动起止点取最近的半小时刻度。超过约 6px 才按拖动处理。从 14:00 刻度拖到 16:00 刻度会得到恰好 2 小时。拖到滚动区上下边缘会自动滚动画布。

一天范围是 00:00–24:00。创建和调整大小会停在相邻块边缘；移动到重叠处会显示红色条纹和文字，松手回到原位置。相邻块可以首尾相接。拖动时按 Esc、收到 pointercancel、丢失指针捕获、窗口失焦或切换日期都会取消预览；中途预览不写入存储。

键盘辅助操作：Tab 聚焦画布，上下键选择时间，Enter 新建。Tab 聚焦块的六点移动按钮，上下键移动，Shift + 上下键调整结束，Alt + Shift + 上下键调整开始，Delete / Backspace 删除。

以桌面鼠标操作为主要验收目标。窄屏提供响应式排版；触屏滚动画布优先，手机手势需另行人工验证。

## 主要文件

```text
src/
  App.vue                    页面布局、工具栏和时间块
  style.css                  浅色文具风格与不同宽度的排版
  themes.css                 浅色与极夜星图夜间模式的界面颜色变量
  main.ts                    启动 Vue 应用
  components/
    TitleEditor.vue          标题输入、自动聚焦与中文输入法处理
    AppIcon.vue              小型 SVG 图标
  composables/
    useCanvas.ts             创建、移动、调整大小、日期与交互状态
    useTheme.ts              手动主题切换、系统默认和偏好保存
  domain/
    palette.ts               五种文具配色、旧颜色兼容与默认颜色轮换
    time.ts                  时间换算、吸附、半开区间、碰撞和边界计算
    storage.ts               本地保存、读取及损坏数据校验
tests/
  time.test.ts               时间与重叠规则测试
  storage.test.ts            存储恢复、损坏数据与失败处理测试
  palette.test.ts            颜色轮换、旧颜色兼容与文字对比度测试
  theme.test.ts              首帧初始化、系统默认、手动偏好与保存异常测试
  canvas.test.ts             Vue DOM事件交互和持久化测试
  setup.ts                   DOM测试所需的指针捕获模拟
```

数据格式：`{ id, date, startMinute, endMinute, title, color? }`。日期使用本地年月日，不通过 UTC 截取。存储键是独立的 `day-canvas.blocks.v1`。无效、重复或重叠的存储记录会跳过并提示，合法记录继续恢复；读取损坏数据后不会立即覆盖原数据，下一次修改才保存新的记录。写入失败时显示提示，并提供重试按钮。

## Visual Polish 01

- 品牌区与画布统一居中，桌面宽度约为窗口的 90%，最大 1760px；小窗口逐级缩小外边距。
- 页面以窗口高度组织，时间轴填满标题和工具栏以外的剩余高度，保留每小时 80px 和完整 24 小时内容。正常桌面窗口主要滚动时间轴，不通过隐藏页面溢出来裁切内容。窗口高度低于 480px 时允许页面滚动，保证控件仍可访问。
- 标题区和工具栏减少纵向留白；窄窗口工具栏可以换行，低高度窗口进一步收紧间距。
- 30 分钟块维持原有 37px 可见高度（40px 时间跨度减去 3px 块间间隔），采用单行紧凑布局；窄窗口隐藏次要时间信息，完整时间可通过标题悬停提示或无障碍名称读取。输入标题时优先给输入框空间；短块的边缘热区避开右侧操作按钮。

当前五色配置集中在 `src/domain/palette.ts`：

| 颜色 | 背景 | 左侧点缀 |
| --- | --- | --- |
| Sage 绿 | `#D7E6C4` | `#91AD70` |
| Lavender 紫 | `#DFD0F4` | `#A68ACB` |
| Sky 蓝 | `#BFDFF0` | `#77B2D4` |
| Peach 橘 | `#F5D3BB` | `#D69C73` |
| Rose 粉 | `#F1CFD8` | `#CC94A8` |

默认颜色取最后一个仍保留的已创建块的当前颜色，按“绿 → 紫 → 蓝 → 橘 → 粉 → 绿”选下一种；没有块或最后一块为旧燕麦色时，从绿开始。轮换依据保存数组的创建顺序，和时间轴排序、日期无关。草稿取消或空标题不消耗颜色；手动改最后一个块的颜色后，下一块从其后接续。删除最后一个块后，从剩余最后一个块接续。颜色随有效标题保存，不新增存储键或业务字段。

旧 `neutral`（燕麦）颜色值与外观继续兼容保留，不出现在新的五色选择器中；已有块不会自动改色。读取或切换日期不触发存储重写，存储键仍为 `day-canvas.blocks.v1`。

本轮自动检查包含新色文字对比度、颜色轮换与取消、手动改色和旧记录保留，以及不同画布宽度、位置下的创建、移动、resize。坐标测试使用模拟 DOM 矩形，**不代表真实浏览器窗口验证**。本轮未启动真实浏览器、Tauri 或 Windows UI 自动化。

## Dark Mode 01

日期工具栏的太阳 / 月亮按钮显示当前 `Light` 或 `Dark` 模式，点击即可手动切换，不按一天中的时间自动切换。

- 第一次访问、没有有效保存偏好时跟随操作系统；在用户手动选择以前，也响应系统的浅色 / 深色设置变化。
- 手动选择使用独立的 `your-24h.theme.v1` 存储键保存，之后优先于系统设置。刷新、重新打开相同地址仍会恢复选择。
- 主题切换只更新界面颜色，不修改日程或颜色 ID。旧燕麦色也有对应的夜间外观，切回浅色恢复原来的显示。
- 鼠标按下主题按钮不会抢走标题输入焦点；未保存文本、光标选区、日期与滚动位置会保留。输入框原有的 Enter / Esc / 失焦规则继续生效。
- 本地存储受限时仍可切换主题，但会提示无法记住偏好。日程保存与主题保存互相独立。

`src/themes.css` 集中定义两套界面变量；`src/domain/palette.ts` 为原有五种颜色及旧燕麦色提供浅色、深色表面。Dark Mode 01 的暖咖啡视觉已由下方 Dark Mode 02 的极夜星图配色替换，仍然只有 Light / Dark 两种模式。工具栏、原生日期选择器、滚动条、当前时间线、拖动选区、冲突、输入、hover / focus 和 resize 状态均有夜间配色。

`public/theme-init.js` 在页面头部同步读取主题偏好，配合 HTML 中的首帧背景和 `color-scheme`，在 Vue 启动前应用主题，以减少深色刷新时的浅色闪烁。不添加整页主题动画；已有细微反馈仍遵守 `prefers-reduced-motion`。

新增测试包括首帧脚本与 Vue 的默认模式一致、手动覆盖系统、刷新恢复、读写受限、监听清理、深色文字与边缘对比度，以及切换时保留输入节点、焦点、选区、草稿和拖动状态。DOM 模拟不能证明浏览器实际绘制、原生控件和首帧没有闪烁；仍未启动真实浏览器或进行 Windows UI 自动化。

本轮人工验收：

- [ ] 用按钮往返切换 Light / Dark，刷新并关闭后重新打开，确认模式保持；已有安排和颜色 ID 不变。
- [ ] 在没有保存主题偏好的测试浏览器中切换系统模式，确认首次跟随；手动选定后系统变化不再覆盖。
- [ ] 新建或修改标题、保持未提交状态，鼠标切换主题后继续输入，再分别用 Enter 保存、Esc 取消。
- [ ] 深色下实际测试创建、反向拖动、移动、上下 resize、重叠回退和边缘自动滚动。
- [ ] 查看五色、旧燕麦色、半小时块、输入提示、调色板、日期选择器、滚动条、当前时间线和焦点框的可读性。
- [ ] 在宽屏和窄窗口检查新增按钮换行；以深色模式刷新检查首帧闪烁，再开启系统减少动态效果设置检查反馈。
